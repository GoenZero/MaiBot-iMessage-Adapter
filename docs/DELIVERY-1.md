## 四、部署（给本地会话）

1. **先备份**树莓派上现有的插件目录：完整复制一份，目录名带上日期。
2. 用 Git 把插件目录换成本分支：
   ```sh
   git fetch origin feature/photon-capabilities
   git checkout feature/photon-capabilities
   ```
   插件目录：`./data/MaiMBot/plugins/<适配器目录>`。如果目录不是 git 仓库，就整体替换成本分支的文件。
3. **Node.js**：插件只要求容器里能运行 `node`（v22 以上）。查找顺序：
   - WebUI「本地侧车 → Node.js 路径」里填的路径
   - 系统 PATH
   - 插件目录下的 `.nodeenv/`
   - 自动下载

   fnOS 数据盘不保留可执行权限时，请在部署层解决，或者把路径填进 WebUI。
4. 重启 MaiBot。MaiBot 会自动安装新依赖 pillow-heif，并把旧配置迁移到 2.0.0，项目 ID 和密钥会保留。**不再需要** `npm install`，也不需要编译。
5. 在 iMessage 里发 `/imessage_status`，看到「✅ 已连接」和能力清单，就说明部署成功了。
6. 旧配置里的「最大附件大小」如果是 10，会原样保留。想用新的默认值 50，到 WebUI 里改。

## 五、回滚

- **整体回滚**：恢复第四节第 1 步的备份；或者在插件目录执行 `git checkout main`，然后重启 MaiBot。注意新配置已经升级到 2.0.0，旧版插件读到会按旧结构重新补齐，项目 ID 和密钥不受影响。
- **只关掉某个功能**：不用回滚代码，在 WebUI「iMessage 能力」里关掉对应开关即可。
- **只撤销某个提交**：`git revert <提交号>`，提交号见第一节。第 1 项是其余各项的基础，不能单独撤销。

## 六、没做的事和已知限制

- **第 3、4 步的功能这次没做**：编辑与撤回、特效、发投票、聊天背景、分享名片、语音发送预留、富链接；对方点赞、投票、已读的注入，以及语音接收。它们会在第二次交付时做。
  - 现在收到对方的点赞、已读等事件，只记一行日志。
  - 收到语音时，AI 会看到「对方发来一条语音消息，你暂时听不了语音」，通常会自然地回一句「听不了」。这还不是第 4 步「先尝试下载转写」的完整做法。
- **TypeScript 版本**：原计划保留 7.x，但 spectrum-ts 12.10.1 声明只支持 TypeScript 5 或 6，所以改用 6.0.3。它只在云端做类型检查，不影响设备。
- **已知安全公告**：OpenTelemetry 有一条中危公告（GHSA-8988-4f7v-96qf）。上游暂无修复。侧车不接收外部请求，遥测默认关闭，不受影响。
- **重启后找不到旧消息**：适配器重启后，「最近消息缓存」会清空。重启前的消息，侧车会先尝试向 Photon 按编号查询；查不到时，点赞会失败并告诉 AI「这次没点成」。
- **「总是引用」档的状态不会保存**：它记的「对方最新一条消息」只在内存里。重启后，要等对方发来新消息才会生效。
